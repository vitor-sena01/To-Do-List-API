Uma aplicação **Full Stack** simples, moderna e intuitiva de gerenciamento de tarefas (To-Do List). O projeto possui um front-end dinâmico construído com HTML, CSS e JavaScript Vanilla, e um back-end estruturado em Node.js com Express para consumo de API RESTful.

> 🎓 **Projeto Acadêmico:** Desenvolvido em dupla para fins de estudo e prática de conceitos Full Stack.

---

## 🚀 Funcionalidades

- ➕ **Criação de tarefas:** Adicione novas tarefas com título e descrição/categoria.
- ✅ **Conclusão de tarefas:** Marque tarefas como concluídas ou pendentes de forma dinâmica.
- 🗑️ **Remoção de tarefas:** Exclua tarefas da lista.
- 🔄 **Comunicação em Tempo Real / API REST:** Integração entre o client-side (`fetch` API) e o servidor Express.
- 📱 **Design Responsivo:** Interface limpa, intuitiva e adaptada para dispositivos móveis e desktop.

---

## 🛠️ Tecnologias Utilizadas

### Front-end
- **HTML5:** Estrutura semântica do projeto.
- **CSS3:** Estilização moderna, variáveis CSS e layout responsivo.
- **JavaScript (Vanilla / ES6+):** Manipulação de DOM, eventos e requisições assíncronas com `fetch`.

### Back-end
- **Node.js:** Ambiente de execução JavaScript no servidor.
- **Express.js:** Framework minimalista para criação das rotas da API REST.
- **CORS & Body-Parser / express.json:** Middlewares para tratamento de dados e requisições.
